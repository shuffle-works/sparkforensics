# Contributing

Issues and PRs are welcome.

Set up with `npm install` and `npm run dev`, then drop a Spark event log onto
the dev server. The contributor guide covers the rest:

- [Contributing](docs-site/contributor-guide/contributing.md): where new content goes, linting, changesets and releases, scope notes
- [Development setup](docs-site/contributor-guide/development-setup.md): commands, the log corpus submodule, the docs site
- [Testing and verification](docs-site/contributor-guide/testing.md): the checks to run before a PR
