The evidence panel under "Show evidence" always shows evidence. Executor Utilization shows its core-time breakdown and the core usage chart, Memory Utilization the chart, the heap peak or the allocated memory-time, Excessive Small Files the average file size, Config Audit the audited setting, Shuffle I/O the per-task read sizes and Speculation Waste the speculative task count. The memory waste finding in the CLI and MCP output carries its allocated memory-time.
